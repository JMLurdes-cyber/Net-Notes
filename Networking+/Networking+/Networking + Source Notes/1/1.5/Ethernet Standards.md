## CONCEPT
Understanding the basics of Ethernet connectivity and the basic differences between types through the use of the IEEE standards.

## KEY TAKEAWAYS
Modern Ethernet comes with many variations such as speed, connectors, cabling or equipment. The [[IEEE | standard]] used is the one that defines the specifics of the connection.

| IEEE Standard | Description         | Media                          | Network Speed          |
| ------------- | ------------------- | ------------------------------ | ---------------------- |
| 1000BASE-T    | Gigabit Ethernet    | [[Copper Cabling\|Copper]]     | 1 Gigabit per second   |
| 10GBASE-T     | 10 Gigabit Ethernet | [[Copper Cabling\|Copper]]     | 10 Gigabits per second |
| 1000BASE-SX   | Gigabit Ethernet    | [[Fiber Communication\|Fiber]] | 1 Gigabit per second   |

To decipher the standard into information, we can check each individual piece as a standalone.

For example:

1000BASE-T becomes:
	1000 ---> BASE ---> T or in other words Number * Type - Letter
	- Number : The speed of the transmission (1000 = 1 Gigabit, 10G = 10 Gigabits)
	- Type : The kind of transmission (Base = Single frequency)
	- Letter: The transmission media (T = Twisted Copper)

## INSIGHT
This was a short summary to get a general idea of the different kinds of transmission, and the standards that are used to define it. It allows to show the amount of thought that each single part of the process requires, since picking the right kind of cable is essential to perform the required task, which wouldn't be the case if each single association used their own standard instead.
