*VPNS* usually connect via Software or through the use of ***Concentrators***, be it stand-alone devices or built-in in firewalls that manages the encryption, decryption and tunneling of inputted information.

There are multiple ways of communication, like:
- ***SITE TO SITE***: Direct communication between the corporate network and a remote site, either desktops or private users, through the use of VPN.
- ***TRANSPORT MODE***: Creates an IPSec Header and a Trailer surrounding the data, but not the IP Header. If this packet were to be captured, the hacker would be able to see where it is intended to go, but not the data itself
- ***TUNNEL MODE***: Both IP Header and Data are encrypted between the IPSec Header and Trailer, but creates a New IP Header to give the IP of the concentrator, not the end goal.
